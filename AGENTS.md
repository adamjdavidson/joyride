# Joyride

Joyride is an initial experiment whose core product is the web interface. Keep setup usable without hardware or API credentials. Use README.md for entry points and docs/CUSTOMIZING.md when changing activities, perspectives, levels or steering.

Public examples use public figures or unnamed methods and distinguish source evidence from interpreted behavior. Keep credentials, personal photographs, private context and machine identifiers out of source. Optional adapters and firmware stay separately runnable.

Run npm test and npm run check for application changes. Hardware and live API claims require actual evidence; mocked tests do not establish either.
